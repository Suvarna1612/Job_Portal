# Job Portal Web Application

## Overview
The Job Portal is a web application developed to connect job seekers and employers. 
Users can create accounts, search for jobs, apply for jobs, and employers can post job openings and manage applications.

This project is developed using web technologies to simplify the job searching and recruitment process.

## Features
- User Registration and Login
- Job Posting by Employers
- Job Search Functionality
- Apply for Jobs
- View Applied Jobs
- Employer Dashboard
- Database Storage for Users and Jobs
- Secure Authentication System

## Technologies Used
- Frontend: HTML, CSS, JavaScript
- Backend: Node.js, Express.js
- Database: MongoDB
- Version Control: GitHub

## Installation Steps
1. Clone the repository
2. Open the project folder
3. Install dependencies using:
   npm install
4. Start the server using:
   npm start
5. Open browser and go to:
   http://localhost:3000

## Project Structure
- routes → Contains all route files
- models → Database models
- views → Frontend pages
- public → CSS and JavaScript files
- app.js → Main server file
